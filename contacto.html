Contacto y correcciones

Ahorro Claro es un proyecto de herramientas para entender el consumo eléctrico del hogar. El código y las incidencias se mantienen en la cuenta pública de GitHub carlitosss33.

Comunicar un error o proponer una mejora

Utilizamos el apartado de incidencias del proyecto para recibir consultas sobre las herramientas. Para abrir una incidencia necesitas iniciar sesión en GitHub.

Ver incidencias y comunicar un problema →

Los mensajes de ese apartado son públicos. Describe el problema sin incluir nombre completo, dirección, teléfono, números de contrato, documentos ni fotos de facturas con datos personales.

Qué ayuda a reproducir un cálculo

  • La dirección de la calculadora y el navegador utilizado.
  • Los valores numéricos de ejemplo y la unidad de cada dato.
  • El resultado que aparece y el que esperabas, indicando por qué.

No hace falta compartir tu factura para comprobar una fórmula. Puedes usar valores ficticios que reproduzcan el mismo problema.

Cómo tratamos las correcciones

Revisamos la fórmula y sus supuestos, corregimos los errores que se confirmen y dejamos los cambios en el historial público del proyecto. La fecha editorial de una página cambia cuando se revisa su contenido.
